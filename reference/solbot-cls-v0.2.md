# Solbot 的 Sol-CLS v0.2 实现与运行记录

本文记录 Solbot 的部署配置与运行观测结果。机制归纳截至 2026-11-05，运行数据按下表所列版本与日期统计。

## 运行分工与条目管理

Sol 在前台交流或后台审阅中判断材料的含义，编写理解正文与短摘要，选择修订、共存、替代、分离或暂缓。两个入口共用材料认领、目标版本和逐项回执。Luna 负责目录定位及按请求取证。宿主分配稳定条目身份，维护目录、历史和来源权限，执行版本核验、投递核对与当前视图发布。目录调整通过内部别名接续既有引用，对话使用获准读取的记忆内容。

| v2.6 部署项 | 当时采用的口径 |
| --- | --- |
| 普通记忆 | 新材料形成增量，封存后由相关新证据触发后续判断。旧普通记忆的六小时和七天语义复核已退役。 |
| 开放条目封存 | 自首次持久建立起满 24 小时、发生 8 次实际语义增量或正文达到 1,200 字，任一条件达到即封存。读取、重复提交、重试和无变更审阅均排除于增量计数。 |
| 独立人格档案 | 主 Sol 使用 Medium 档，每六小时独立审阅。需要补充证据时由 Luna 定位。Update 生成新版本，No_update 保存覆盖范围和完成时间。身份、安全和既定外形由授权来源维护。 |
| 技术失败的重判 | 正常尝试累计三次后封停，满七天安排一次单独重判。再次失败时退出执行队列，保留原文、错误和历史次数。 |

## 证据与运行表现

以下记录来自不同版本和工作负载。请求投影、模型调用、材料回执和自然投递分别计量。

| 版本与证据类型 | 观测对象与结果 |
| --- | --- |
| v2.6，故障快照离线重放 | 保留 222 个理解版本、927 份直接原文和 3,745 个传递曝光来源。共享依赖清单启用后，输入估算从 839,112 降至 266,668 tokens，含输出预留的总投影从 971,208 降至 398,764 tokens，下降约 58.9%。 |
| v2.6，迁移、回退演练及正式切换 | 在实际数据副本上演练安装与回退，安装后的新增写入保存在库中。回退时隐藏旧程序无法核验的派生视图，重新启用后按实时来源逐项恢复。最终生产切换保留 19,540 条原始记录。 |
| v2.6，隔离真实模型 | 共 13 次真实调用，其中 10 次结果通过对应宿主校验，另 3 次首轮人格覆盖字段被拒。修正字段说明与格式约束后复验通过。独立档案的 Update 和 No_update 各有一次隔离实例。 |
| 11 月 5 日自检，自然调度 | 首轮自然人格审阅覆盖三个已配置范围，两项 Update、一项 No_update，均有真实模型与提交回执。重启后新增且仍为当前版本的 49 项普通理解通过来源与权限核验。 |
| v2.71，实库副本及生产恢复 | 旧索引在写事务中反复展开来源，复测 45 秒完成 132 条中的 28 条。调整为同一快照内复用来源校验后，同一副本的 132 条完整同步耗时 5.62 秒。生产中一条中断轮次恢复了结束状态。 |
| v2.72，两群自然回复 | 历史读取与发送前校验各自采用操作当下的一致快照。上线后四条自然回复均完成投递，并与群历史回读结果一致。上下文组装耗时 7.39–30.46 秒，发送耗时 4.83–11.07 秒，工作线程总耗时 35–83 秒，排队另计 4–29 秒。 |

截至 2026-11-06，维护记录将“纠正或撤回后，换问法是否会从旧摘要或旧回信恢复旧结论”列为 P2 待观察项。来源校验的证据是版本与权限记录，语义回流的判定需要核对后续问题的实际输入和回答。
